#This is the over-view of the entire Edufa system.

#Problem Statement
Many firms for student bursary or scholarships fail to award the students in need but award those with out a great need of the bursary, 
Edufa(Education for All ) comes in to help the admins decide critically on who should be given the scholarship first.
it will calculate accordingly to the info provided by the applicant. and help the admins to decide by summarizing all the info.

#The Tech Stack of the Edufa
The System entirely depends on TypeScript as it was used as the core language, then comes in Tailwind, bootstrap to main consistency of the system.

The system is also integrated with Cloud sql to store, manage and retrieve the systems data
